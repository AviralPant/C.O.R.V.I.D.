# W.E. ObsidiaN - 7

## Features

- Real-time voice conversations with Gemini Live.
- Optional local speech recognition and speech synthesis.
- Support for Gemini, local models, and third-party AI providers.
- Multilingual speech input and voice responses.
- Optional wake-word detection and push-to-talk.
- Animated avatar with facial expressions and real-time lip sync.
- Reactive HUD with live theming and video playback.
- Screen and webcam visual awareness.
- Persistent, searchable memory and session summaries.
- Voice control for applications, windows, volume, brightness, Wi-Fi, and power.
- Browser control, web search, and dynamic content display.
- Local file processing and computer-assisted tasks.
- Plugin system for adding assistant skills.
- Workflow recording, queued execution, and undo.
- Permission controls and confirmation for sensitive actions.
- Audio device and voice selection.
- Model fallback, session continuity, and long-running conversations.
- Reminders, weather, briefings, and proactive notifications.
- Hardware monitoring with voice alerts.
- Phone dashboard for remote access.
